VECTOR DATABASE

Real pgvector storage

Document chunks are rows in PostgreSQL and embeddings are stored in a native vector(384) column. HNSW accelerates semantic nearest-neighbour search.

KEYWORD RETRIEVAL

PostgreSQL FTS

A generated tsvector column and GIN index preserve exact ESG terminology such as Scope 3, BRSR Core and assurance.

FUSION

Reciprocal Rank Fusion

Semantic and full-text result lists are merged using RRF so neither exact terminology nor semantic intent dominates by default.

SECURITY

RLS + server-side writes

The browser receives only the public Supabase key. Database writes and retrieval logging happen inside JWT-protected Edge Functions using the service role.

GROUNDING

Evidence contract

The generation endpoint is instructed to use only [E#] evidence, identify boundary/year differences and abstain when retrieval is insufficient.

AUDITABILITY

Retrieval logs

Queries, filters, returned chunk IDs and retrieval latency are recorded server-side for future evaluation and debugging.
